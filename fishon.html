FishOn

Voici la présentation de mon projet de fin de formation "Fondamentaux Développement Web".

Cette application est le fruit d'une collaboration avec ROBLES Corentin.

Nous avons créé FishOn, une application web permttant :

  • La mise en relation des passionnés de pêche.
  • Le partage de publications et d'expériences entre utilisateurs.
  • Une interface simple et intuitive.

    • Technologies

    BackEnd : Java 21, Spring Boot 3.5.0.

    FrontEnd : JavaScript, HTML5, CSS3

    Data : PostgreSQL
